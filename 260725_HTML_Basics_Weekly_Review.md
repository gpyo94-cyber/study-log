HTML Boilerplate
DOCTYPE : Tell the browser of HTML's version.
html : root of the document. every element is its descendant
head : meta-information about the page, not displayed on the page
body : everything you can see on webpage
title : inside head, but visible on the browser tab
meta : 'about'  <meta charset="UTF-8"> -> makes every language display correctly (Korean doesn't break)
tag : keywords wrapped in angle brackets < > that mark the start and end of an element. <p>, </p>
element : opening tag + content + closing tag. <p>Hello</p> = one element
void element : there is no closing tag <img>, <br>
HTML is a tree structure : html = root, direct inside = child, same parent = siblings, any level inside = descendant. CSS will use these relationships
rm -r -> remove recursive — deletes a folder including everything inside it
mv - move
'-' option marker. attaches extra options to a command (e.g. -r in rm -r, -m in commit -m)
