add : put changes on the stage (cart)
commit : save a snapshot of staged changes to my computer's history
push : upload commits to GitHub
ahead by 2 : two commits are saved on my computer but not pushed to GitHub yet
origin : my local repo's nickname for the GitHub repo (the remote address)
main : the name of the branch where commits stack up
pwd : print working directory (where are you)
q : quit the log viewer (END screen)
git status
git add .
git commit -m "name"
git push
